# Product Overview

ExpenseTracker is an Android mobile application for personal expense management and financial tracking.

## Core Features
- Track individual expenses with categories, tags, and descriptions
- Manage recurring expenses for subscription tracking
- Categorize expenses for better organization
- Support for multiple currencies
- Data visualization with charts (using Vico library)

## Target Platform
- Android mobile application
- Minimum SDK: API 33 (Android 13)
- Target SDK: API 34 (Android 14)

## Key Domain Concepts
- **Expenses**: Individual financial transactions with amount, category, tags, and timestamps
- **Categories**: Organizational structure for grouping expenses
- **Recurring Expenses**: Automated tracking for subscriptions and regular payments
- **Multi-currency support**: Handle different currencies for international users
